# API gateway
___
### Environment variables
`GATEWAY_PORT` - application.yml - server.port  
  
`EUREKA_URL` - application.yml - eureka.client.serviceUrl.defaultZone  

`REDIS_HOST` - application.yml - spring.redis.host

`REDIS_PORT` - application.yml - spring.redis.port

`IS_STUB` - application.yml - api-gateway.isStubEnabled
